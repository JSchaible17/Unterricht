## Klasse 8 – WR

- [Einrichtungen des Verbraucherschutzes](https://jschaible17.github.io/Unterricht/klasse-8/wr/verbraucherschutz/)

Jeder Spielordner enthält seine eigene index.html und die zugehörigen Dateien. Die Ordnerstruktur lautet klasse-<Nummer>/<Fach>/<Thema>/. Fach- und Themennamen in Adressen werden klein geschrieben, der Repositoryname Unterricht beginnt entsprechend dem angelegten Bereich mit einem großen U.

GitHub Pages veröffentlicht main, /(root). Die Datei .nojekyll erhält die HTML-/JS-Struktur. Die bisherigen Lernspiel-Adressen bleiben in den ursprünglichen Repositories bestehen, damit bereits verteilte QR-Codes funktionieren.

Nur Schüler-Lernseiten veröffentlichen. Präsentationen, Lehrerunterlagen und Lösungen bleiben im lokalen Unterrichtsordner.
